# 갤럭틱 나이트 울트라 (Galacta Knight Ultra)

『별의 커비 Wii 디럭스』의 히든 보스인 갤럭틱 나이트의 하드모드입니다.

## 주요 특징 및 주의사항 (Notes)
* 갤럭틱 나이트 하드모드와 진 격투왕의 길에서 첫 번째 보스로 갤럭틱 나이트가 등장하는 모드는 별개입니다. 두 모드는 서로 호환됩니다.
* 호환성 안내: 다른 모드와의 호환성은 테스트되지 않았습니다.

## 설치 방법 (Installation)
1. 오른쪽 Releases 메뉴에서 최신 버전의 `.zip` 파일을 다운로드합니다.
2. 압축을 해제한 뒤 내부의 `romfs`, `exefs` 폴더를 기기(또는 에뮬레이터)의 모드 적용 경로에 넣습니다.
   * 에뮬레이터(Ryujinx / Yuzu 등): 게임 우클릭 → `모드 디렉터리 열기` 후 압축 해제한 폴더 붙여넣기

## 이용 안내 (Permissions)
* 개인 플레이 용도로만 사용 가능합니다. 자유롭게 다운로드하여 플레이하실 수 있습니다.
* 제작자의 명시적인 허락 없이 타 사이트 재업로드, 무단 배포 및 다른 모드팩에 포함하는 행위를 금지합니다.
